# Kwiatki

Comiesięczny przegląd roślin z Claude.

## Co miesiąc

1. **Zdjęcia.** Sfotografuj każdą roślinę: cała roślina z doniczką, w dzień, najlepiej bez ostrego słońca, z tej samej strony co zwykle. Jeśli coś jej dolega, zaraz potem zbliżenie (liść, spód liścia, podłoże). Ta sama kolejność co miesiąc ułatwia dopasowanie.
2. **Wrzuć je do `nowe/`.** Na GitHubie: folder `nowe` → Add file → Upload files → Commit. Można też załączyć je w czacie z Claude.
3. **Napisz do Claude** w sesji z tym repo: „przegląd kwiatków” albo `/kwiatki`. Możesz dopisać, co robiłeś od ostatniego razu (przesadziłem fikusa, monstera stoi teraz w salonie).

## Co dostajesz

- `raporty/RRRR-MM.md` – co się poprawiło, co pogorszyło, plan podlewania i nawożenia na miesiąc, zakupy, pytania.
- `rosliny/<roślina>/dziennik.md` – historia rośliny ze zdjęciami miesiąc po miesiącu.
- `rosliny/README.md` – wszystkie rośliny w jednej tabeli.
